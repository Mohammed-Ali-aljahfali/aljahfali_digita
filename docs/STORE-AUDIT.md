## أخطاء مؤكدة

1. قراءة JSON السلة دون معالجة الخطأ قد توقف التنفيذ قبل تحميل المنتجات. الاتصال الخارجي دون مهلة أو إعادة محاولة واضحة، والاستجابة الفارغة تعيد منتجات قد تكون أوقفت فعليًا.
2. سياسات SQL تسمح علنًا بتعديل المنتجات والإعدادات والطلبات، وقراءة بيانات العملاء. تعديل الملف الشخصي لا يستثني role.
3. حماية الإدارة PIN مكشوف ومتغير sessionStorage؛ ليست صلاحية خادمية.
4. تسجيل الدخول والتسجيل يولدان مستخدمًا محليًا وهميًا عند غياب الإعداد. استعادة كلمة المرور رسالة بلا استدعاء API. الحساب يثق بهذه الهوية.
5. حفظ الطلب يبتلع فشل Supabase ويعلن نجاح النسخة المحلية، ويثق بالهوية والأسعار والحالة القادمة من المتصفح. لا يوجد منع للتكرار أو قيد على الانتقالات.
6. إدراج بيانات المنتجات والعملاء والطلبات داخل innerHTML دون تهريب يسمح بحقن HTML.
7. تعديل أسعار الإدارة يكتب محليًا قبل تأكيد السحابة. السلة تحفظ أسعارًا قديمة وتظل بالدولار عند اختيار عملة أخرى.
8. روابط services.html وterms.html وprivacy.html مفقودة؛ روابط الإدارة ظاهرة للعملاء. Sitemap يستعمل namespace غير صحيح وينقصه المتجر، وصفحات الحساب والإدارة دون noindex.
9. اختبارات المشروع القديمة تفحص وجود نصوص وعناصر، ولا تختبر صحة الأسعار أو الصلاحيات أو المعاملات.

## موجود وسليم بحسب الفحص المحلي

ملفات الكتالوج والشعارات سليمة وقابلة للقراءة، وتحتوي أسعار العملات الأربع والتفاصيل العربية. البحث الأساسي والتصنيف وتقسيم العرض موجودة ومنطقها قابل لإعادة الاستخدام. بقية صفحات الموقع وهوية الألوان والشعار محفوظة. لا يمكن تأكيد نجاح عمليات الإنتاج دون اختبار اتصال مصرح به.

## موجود لكنه غير مكتمل

المصادقة وGoogle، ملفات العملاء، عرض المنتجات، إدارة الأسعار، سلة محلية، إنشاء الطلبات، الإعدادات والتسليم. إعداد Supabase يضم URL فقط، ولا يوجد مفتاح عام في الملفات ولا متغير اتصال متاح. مفتاح عام محفوظ داخل متصفح المالك لا يُهيئ متصفحات العملاء.

## مفقود

صفحة منتج مستقلة؛ باقات مستقلة؛ تسعير خادمي؛ سندات خاصة؛ وسائل دفع ديناميكية؛ مراجعة الدفع؛ سجل الحالة؛ كوبونات؛ اشتراكات وتجديدات؛ إشعارات وتذاكر؛ صلاحيات وقواعد وصول صحيحة؛ تكلفة وربح خاصان؛ سياسات قابلة للمراجعة؛ سجل تدقيق واختبارات معاملات.

## يحتاج اختبارًا خارجيًا أو مراجعة المالك

- بنية Supabase المنشورة وسياساتها ونسخها الاحتياطية ومزود Google وSMTP وروابط إعادة التوجيه؛ ليست متاحة محليًا.
- إعداد الاستضافة، HTTPS ورؤوس الأمان، زمن الشبكة وCore Web Vitals على أجهزة حقيقية.
- بيانات حسابات الدفع والأسعار والصرف؛ لا ننشئ أرقام حسابات أو أسعارًا تجارية جديدة.
- محتوى المنتجات الأصلي يتضمن ادعاءات عن الميزات والضمان والاعتماد. نحتفظ بالبيانات، ولا نقدمها على أنها تحقق حديث من المزود. يحتاج تحديث المحتوى ومصادره واعتماد الضمان مراجعة قبل النشر.
- قيم sold في الكتالوج مولدة في سكربتات البناء؛ لا تصلح أساسًا لشارة «الأكثر مبيعًا». الترتيب الجديد يعتمد الطلبات الموثقة.

## التصميم المعتمد

تطوير المشروع نفسه، إبقاء العملات والأسعار الأصلية، إضافة ترحيلات قابلة للتتبع غير حاذفة للبيانات، وقصر العمليات المالية على دوال PostgreSQL ذرية. يسمح الكتالوج المحلي بالتصفح عند غياب الربط؛ الطلبات والمدفوعات تتوقف برسالة واضحة حتى يتوفر خادم موثوق. جميع الاختبارات تستخدم بيانات معزولة. لا نشر فعلي ضمن هذه المرحلة.
