# تسليم النسخة المحلية — 26 نوفمبر 2026

تطوير المتجر داخل المشروع الحالي مكتمل محليًا واجتازت الاختبارات المذكورة أدناه. لم تُطبّق الترحيلات على قاعدة الإنتاج ولم تُنشر الملفات على الموقع الحي. إعداد `supabasePublishableKey` فارغ؛ لذلك تتيح النسخة الحالية تصفح الكتالوج والسلة وتوقف الحسابات والطلبات إلى أن يكتمل الربط الفعلي.

## ما أصبح متاحًا

- كتالوج عربي RTL، بحث بالعربية والإنجليزية، تصنيفات وفلاتر وباقات وعملات، وصفحة منتج قابلة للمشاركة. بقيت المنتجات الـ34 وأسعارها وبياناتها الأصلية مطابقة لبصمات الفحص الأولي.
- سلة تحفظ المعرفات والكميات، وتتزامن بين التبويبات. التسعير النهائي والتحقق من المخزون والكوبون والعملة من الخادم.
- إنشاء طلب ذري بمفتاح يمنع التكرار، واستعادة الطلب عند ضياع استجابة الحفظ، دون تفريغ السلة عند الفشل أو حذف إضافات لاحقة.
- وسائل تحويل قابلة للإدارة، إثباتات خاصة، تحقق خادمي من نوع الصورة وحجمها وملكية الطلب، مراجعة دفع منفصلة عن إرسال السند.
- تسجيل ودخول واستعادة كلمة مرور عبر Supabase، حساب للطلبات والمدفوعات والاشتراكات والتجديد والدعم والإشعارات.
- إدارة المنتجات والباقات والتصنيفات والأسعار والصرف والطلبات والمدفوعات والاشتراكات والتجديدات والعملاء والصلاحيات والكوبونات والتكاليف والتقارير والسياسات وسجل العمليات.
- قواعد وصول وصلاحيات أعمدة تمنع انتحال دور المدير أو رؤية بيانات عميل آخر، وحفظ سعر الطلب وتكاليفه وقت الإنشاء.
- ترحيل غير حاذف للبيانات، مع رفض السياسات السابقة غير المراجعة. طابور واتساب مستقل دون إرسال فعلي.

## الإصلاحات التي أُغلقت في هذه المتابعة

1. توقف تهيئة لوحة الإدارة بسبب زر صيانة مفقود من HTML؛ أُضيف الزر واختبار تشغيل فعلي للصفحة.
2. إتاحة إلغاء الطلب المسموح به للعميل، ومنع إلغاء الطلبات التاريخية التي تفتقد الحالة الجديدة.
3. مزامنة السلة والعملة بين التبويبات وإبطال عروض الأسعار القديمة، والتعافي من قيمة `null` في التخزين المحلي.
4. الاحتفاظ بمعرف محاولة الطلب واستعادة الطلب المحفوظ بعد مهلة الاتصال أو إعادة تحميل الصفحة، حتى عند تغير بيانات النموذج.
5. تحديث قائمة الباقات عند تغيير المنتج في محرر التكلفة، وإبقاء بيانات المنتجات القديمة غير المعدلة.
6. منع اكتمال التجديد بلا طلب جديد مؤكد الدفع يخص العميل نفسه والمنتج والباقة نفسها.
7. منع تجديد الاشتراكات الملغاة، وتسمية زر التصفية لقارئ الشاشة على الجوال، وتصحيح روابط الصفحات والسياسات.

## نتائج التحقق

| الفحص | النتيجة |
| --- | --- |
| `npm test` — وحدات الأسعار والعميل وDOM الفعلي | 28 ناجحة |

| `npm run check` | 17 صفحة، 34 منتجًا، دون أخطاء أو تحذيرات |
| `git diff --check` | ناجح |

التشغيل المجمع ينتهي برمز خروج 0. السجل المحلي: `test-results/final-tests.log` و`test-results/static-check.json`. تستخدم الاختبارات بيانات معزولة وPGlite وواجهات محاكاة، ولا تنشئ مستخدمين أو طلبات أو مدفوعات حقيقية ولا ترسل رسائل.

جرّبنا في المتصفح المحلي البحث وتغيير العملة وفتح المنتج والإضافة إلى السلة والانتقال إلى الدفع، وحالة عدم تهيئة الحسابات وحارس الإدارة. لم تسجل الصفحات المفحوصة أخطاء JavaScript. تحققت أبعاد صفحة المتجر عند 320 و390 و768 و1440 بكسل دون تجاوز عرض المستند، وصور الصفحة المحملة سليمة. فُحصت صور المنتج والسلة والكتالوج بصريًا على عرض الجوال. لقطة محفوظة: `test-results/store-mobile.jpg`.

هذا فحص لعروض ممثلة في متصفح واحد؛ ليس اعتمادًا لجميع الأجهزة أو قارئات الشاشة. العرض المرئي لالتقاط شاشة الكمبيوتر داخل لوحة المعاينة كان مقصوصًا، لذلك لا يُعد بديلًا عن اختبار الكمبيوتر الفعلي. الحسابات المسجلة ونماذج الإدارة اختُبرت آليًا على DOM الحقيقي بواجهات معزولة، ولم تدخل جلسة إدارة إنتاجية.

## قياس الحجم وحدود قياس الأداء

قيس حجم HTML وملفات CSS/JavaScript المحلية المحمّلة مباشرة من صفحة المتجر. النتائج مقارنة بـ`c2425ac`:

| القياس | قبل | بعد |
| --- | ---: | ---: |
| الملفات المحلية دون ضغط | 256,560 بايت | 442,575 بايت |
| مجموع ضغط gzip لكل ملف | 51,388 بايت | 111,333 بايت |

تفاصيل الملفات في `test-results/performance-assets.json`. المقارنة لا تشمل الصور والخطوط أو SDK الخارجي في النسخة السابقة؛ أصبح SDK محليًا وثابت الإصدار في النسخة الجديدة، لذلك لا تمثل الأرقام مقارنة كاملة لحجم التنزيل. ضغط gzip هنا قياس محلي، وليس تأكيدًا لتفعيل الضغط على الاستضافة. لم تُقَس Core Web Vitals أو سرعة الشبكة على الإنتاج، ولا ندعي نسبة تحسن غير مقاسة.

## ما يلزم قبل البيع الفعلي

- تطبيق [دليل Supabase والنشر](SUPABASE-DEPLOYMENT.md) على مشروع تجربة: الترحيل، الدالة، الأصول المسموح بها، المفتاح العام، البريد وGoogle إن استُخدم.
- إدخال بيانات التحويل الحقيقية واعتماد الأسعار والصرف والسياسات والضمان. المحتوى التاريخي للمنتجات محفوظ ولم تُعتمد صحة ادعاءاته أو حداثته لدى المزود؛ يلزم مراجعته قبل النشر.
- تجربة دورة شراء ودفع وتفعيل فعلية في البيئة التجريبية، مع حسابين مستقلين واختبار عزل السندات وصلاحيات الإدارة.
- التجديد يتطلب تنفيذ التفعيل وتحديث تاريخ الاشتراك يدويًا بعد مراجعة الدفع؛ تغيير حالة متابعة التجديد لا يمدد الاشتراك تلقائيًا.
- الصيانة وإشعارات قرب الانتهاء تعمل عند تشغيل زر الصيانة. لا يوجد cron منشور، ولا عامل إرسال WhatsApp Cloud API. المتجر يحفظ الأحداث دون الاعتماد على إرسال واتساب.
- روابط واتساب وفيسبوك وإنستغرام وبعض روابط Telegram لم يمكن التحقق من استجابتها بسبب قيود الشبكة؛ لا تُصنف كروابط معطلة أو سليمة دون اختبار. نتيجة الفحص السابق في `test-results/external-links.json`.
- روابط المنتجات وعناوينها وبياناتها المنظمة تتحدث عبر JavaScript. معاينات المشاركة ومحركات لا تنفذ JavaScript قد تحتاج توليد صفحات ثابتة لاحقًا.
