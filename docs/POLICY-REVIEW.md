# مسودات السياسات — للمراجعة قبل النشر

هذه نقاط تحريرية وليست شروطًا معتمدة أو استشارة قانونية. صفحات المتجر لا تعرضها تلقائيًا. تُكتب النسخ النهائية في لوحة الإدارة ضمن السياسات، مع إبقاء `published=false` حتى اعتماد المالك. لا نضع مدد استرجاع أو ضمان أو وعود تسليم غير مقدمة من المالك.
